# 方案设计（v2）

> v1 的假设是“分辨率—稳定性曲线会收敛到一个平台”，并用拍定的 0.85 阈值判定断崖。
> 该假设已被数据否定（详见 `ai-log/01`、`02`）。本文件只保留 v2 的设计。

## 研究问题

H3 落格前必须选一个分辨率。课件给了面积量级，但选档原则只有定性建议。本研究回答：

  **在给定数据与业务尺度下，如何选出一个"最小充分分辨率"，且这个判据不依赖拍出来的常数？**

## 核心思路（v2）

把"跨尺度是否稳定"换成"**跨尺度损失是否超出采样极限**"：

1. **可靠性天花板 O_r**：同一分辨率下，按 6 小时时段分层随机对半，两半各自取密度 Top-100，
   计算重合率。这是该档任何估计的可复现性上限。
2. **跨尺度一致率 C_r**：同一半内，res r 与 r−1 的 Top-100 父格命中率。
3. **归一化尺度稳定指数 SSI = C_r / O_r**：
   - SSI ≈ 1 → 细化没有超出采样噪声；
   - SSI < 1 → 细化额外损失稳定性。

## 判据

取最细的 r，使 **O_r ≥ ρ**（ρ 为分析者声明的可靠性下限，本文取 0.90）。
不再使用"一致性 ≥ 0.85"这类无依据阈值。

## 实验

- E1 面积均匀性：H3 不随纬度变化，但同档内 max/min ≈1.97–1.99×（官方 restable），五边形≈0.505×
- E2 分辨率稳定性：res 4–9 的嵌套一致率与等质量 IoU
- E3 样本充分性：每格点数随分辨率的变化
- E4 时段稳健性：4 个 6 小时时段
- E5 网格对照：H3 / Geohash / 等经纬（局部 CV 与全球极差）
- **E6 可靠性天花板与 SSI（原创点）**

## 被否掉的方案（保留记录）

| 方案 | 否掉的原因 |
|---|---|
| 跨分辨率 Top-K IoU | 等 K 不等面积，指标无信息量 |
| 质心漂移 | 测的是格子边长，不是热点稳定性 |
| 零模型校准 0.85 | 只能证明"非随机"，无法区分 0.86 与 0.75 |
| 把 1.97× 当原创发现 | H3 官方 restable 已给出，属复现 |
