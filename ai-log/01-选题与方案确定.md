## 第 5 轮 · 推仓库时的连环障碍

**我的输入**

按 AI 指引建好 Public 仓库 `zju-marine-datamining-final`，然后把地址发给它，出现了
浏览器授权失败的截图，问"这是啥情况啊"。

**AI 输出（摘要）**

依次排掉四层障碍，每一步都有实测证据：

1. Git 凭据助手不在 PATH 里 → git 其实一直在悄悄问"用户名"，被终端禁用了
2. 把 GCM 加进 PATH 后，GCM 自己发请求**不走系统代理** → 连接被强制关闭
3. 补上 `HTTPS_PROXY` 能连上，但 OAuth 回调地址是 `http://localhost`（不带端口），
   本地没有监听 → 浏览器显示"拒绝连接"
4. 改用设备码流程，GitHub 端提示 "Your device is now connected"，但 GCM 把凭据存到了
   `api.github.com` 名下，而 git 找的是 `github.com` 名下的凭据，仍然对不上

最后改用 Fine-grained PAT，并发现一个细节：这套便携 Git 上不能用 `x-access-token`
当用户名，必须用账号名 `a8617667120222`，改完之后一次推送成功。

**本轮我确认了什么**

（手写）这轮花的时间比预想多得多，但值得记下来：**AI 的每一步判断都被实际报错推翻过一次**。
它在第 2 步断言"配好代理就行"，结果第 3 步就打脸；第 3 步说"用 Chrome 打开就行"，
第 4 步又被打脸。这说明不能只看它说得顺，要看它有没有真的执行验证。

## 第 6 轮 · 数据到了，先体检

**我的输入**

"好的，等数据下载完请告诉我。"

**AI 输出（摘要）**

- 第一次用异步下载，脚本一退出下载就断了，只拿到 20.7 MB（AI 主动承认并说明原因）
- 改为阻塞式重下，拿到完整 304 MB，解压出 836 MB CSV
- 体检结果：815.6 万条记录、15,932 艘船、完整一天、纬度 2.4°–71.2°
- **关键发现：80%（651 万条）的记录航速 < 1 节**，即静止的锚泊/靠泊船

由此提出一个必须由我拍板的口径问题：

- A 口径：保留全部记录 → 研究的是"泊位热区"（港口识别、锚地规划）
- B 口径：只留 SOG ≥ 3 kn → 研究的是"航道热区"（航路分析、避碰）

**本轮我确认了什么**

（手写）我选 **B 为主、A 为辅**。理由是：我要研究的是"流动的热点"，
静止点本质上是港口位置的重复采样，会把所有分辨率都压成同一张港口地图，
反而看不出分辨率的影响。但 A 不能丢——它正好能当对照，用来论证"静止点占比越高，
分辨率选档越关键"。

## 第 7 轮 · 第一次跑实验，指标设计错了

**我的输入**

"B 为主、A 为辅。"

**AI 输出（摘要）**

跑完 E1–E4 后，输出了一张诡异的表：所有分辨率之间的热点 IoU 都只有 0.10–0.14。

AI 主动判定这是**它自己的指标设计错误**，给出理由：Top-100 在不同分辨率下覆盖的
面积差了约 50 倍（res7 的 100 格 ≈ 516 km²，res9 的 100 格 ≈ 10 km²），
拿面积差 50 倍的两个区域求交并，数学上必然趋近于 0.02–0.1，这个数没有信息量。

随后换成两个新指标：

- **嵌套一致率**：细档热点格的父格是否落在上一档的热点集合里（利用 H3 父子层级）
- **等质量 IoU**：每档都取"累计覆盖 50% 点数"的区域再比，质量对齐后面积才可比

**本轮我确认了什么**

（手写）这是我第一次真正"审"AI 的产出，而不是接受它。判断依据很简单：
**一个指标在 5 个档位上给出几乎一样的值（0.10–0.14），它一定没有在测量分辨率。**
这是常识性的反证，不需要懂 H3 也能看出来。

## 第 8 轮 · 假设被数据打掉

**我的输入**

（等待结果，此处为 AI 主动汇报）

**AI 输出（摘要）**

新指标下的结果，与我原本的假设冲突：

| res | 嵌套一致率（航行船） | 嵌套一致率（全量） |
|---|---|---|
| 5 | 0.899 | 0.955 |
| 7 | 0.877 | 0.863 |
| 8 | 0.862 | 0.747 |
| 9 | **0.747** | 0.727 |

三条与原假设不符的结论：

1. **不存在收敛平台**。原假设是"先降后平"，实际是缓慢下滑后突然崩塌，
   等质量 IoU 全程锁在 0.33 根本没有收敛趋势
2. **质心漂移是伪指标**。16.9 / 6.5 / 2.5 / 0.9 / 0.35 km 几乎等于各档网格边长，
   它测的是格子大小，不是热点稳定性
3. **静止点会显著恶化问题**。全量数据在 res8 就掉到 0.747，航行船还能稳在 0.862

AI 据此提出改写主线：稳定性不是"收敛—平台"结构，而是"缓慢衰减 + 由采样充分性
触发的断崖"；触发断崖的不是 MAUP 几何效应，而是样本稀释（res9 每格中位数仅 1 个点）。

**本轮我确认了什么**

（手写）我同意这条主线。因为它把 MAUP 这个**纯几何问题**和**统计上的样本量问题**
绑在了一起，而课件是把它们当两件事分开讲的——这个"合起来"的动作，才是这份报告
真正属于我自己的东西。原来的"找平台"版本反而只是在复述课件。
