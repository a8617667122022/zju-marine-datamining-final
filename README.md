## 选题说明

对应课程第 3 讲"空间"中的 H3 网格落格环节。课件给出了各分辨率对应的格子面积，
但选档原则只有"按业务尺度、数据质量和样本量选档"这一句定性描述。本课题把这句话
变成可计算、可复现的判据，并用公开海洋数据做实证验证。

核心产出：

1. **RSC（分辨率–稳定性曲线）**：量化"换一档网格，热点结论会不会搬家、搬多远"
2. **MSR（最小充分分辨率）判据**：同时约束结论稳定性与每格样本充足性
3. **面积归一误差的纬度函数**：把"密度必须除以有效海域面积"从口号变成容差公式
